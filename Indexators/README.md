# Лабораторная работа: Индексаторы в C# (.NET 9)

## Как запустить
1. Откройте `IndexatorsNet9.csproj` в Visual Studio 2022 (с установленным .NET 9 SDK).
2. Запустите проект клавишей F5 или командой `dotnet run`.

## Что реализовано
- Задание 1: классы `Book` и `Library`, целочисленный индексатор, проверка границ, замена книги и перехват `ArgumentOutOfRangeException`.
- Задание 2: `CompanyCatalog` с перегруженными индексаторами `int` и `string`; `UserContainer` со строковым индексатором через `switch`; обработка отсутствующего сотрудника.
- Задание 3: `GameGrid` с двумерным индексатором и `private set`; заполнение через `SetCell` и вывод матрицы.

Попытка присвоить `grid[0, 0] = 5` из `Main` оставлена в комментарии: если раскомментировать строку, компилятор выдаст ошибку CS0272, поскольку сеттер закрыт модификатором `private`.
