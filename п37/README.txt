ПЗ7 — проект C# под .NET 9

Как запустить:
1. Откройте папку PZ7_NET9 в Visual Studio 2022 или Rider.
2. Убедитесь, что установлен .NET 9 SDK.
3. Запустите проект (F5) либо выполните в терминале:
   dotnet run

ВАЖНО ПРО ЗАДАНИЕ 3:
В методичке используется C# 14 / .NET 10. Отдельные нестатические операторы
составного присваивания (например, public void operator +=(...)), а также
virtual/override для них, в .NET 9 / C# 13 не поддерживаются.

Поэтому проект адаптирован под .NET 9:
- обычное += работает через статический operator + и создаёт новый объект;
- AddInPlace и MergeInPlace показывают изменение существующего объекта;
- AddInPlace виртуальный и переопределён в PremiumAccount, где начисляется 5% кэшбэк;
- ++ реализован в допустимой для C# 13 статической форме.

То есть задания 1 и 2 реализованы по спецификации, а задание 3 выполнено
максимально близким способом, который компилируется на .NET 9.
